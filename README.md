# Flappy Block

This is Flappy Block, a game made with SDL3.

## How to play

Download the latest release over [GameJolt](https://gamejolt.com/games/FlappyBlock/1118179).

Controls (Desktop):

- `Mouse click`: Navigate / Fly
- `Escape`: Go back / Exit

Android:
- `Touch`: controls, fly
- `Back button / gesture`: Go back / Exit
